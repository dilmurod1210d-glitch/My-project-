# MegavitFarm — SanaForte karton quti (razvyortka)

SanaForte shabloni asosida MegavitFarm brendi uchun tayyorlangan dori qutisi razvyortkasi (1280×1280 px).

- `sanaforte-dieline.html` — Adobe Express'ga import qilingan manba maket (Montserrat, Adobe Fonts).
- `sanaforte-dieline-preview.png` — ko'rinishi.

Tahrir qilinadigan nusxa: Adobe Express (tahrirlovchi havolasini muallifdan so'rang).

## Bosmaga berishdan oldin to'ldirilishi kerak
- Ishlab chiqaruvchi manzili: `[адрес производителя]`
- TU raqami: `[номер ТУ]`
- Shtrix-kod — namunaviy (4780000000007), haqiqiy GTIN bilan almashtiring.
- QR-kod — bezak uchun namuna, skanerlanmaydi; haqiqiy QR qo'ying.
- Ishlab chiqarilgan / yaroqlilik sanalari.
